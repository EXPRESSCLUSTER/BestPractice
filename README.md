# BestPractice
The documentation provided in this repository describes recommended parameters for a disaster recovery (DR) configuration. Two guides are included:

EXPRESSCLUSTER X 4.1 best practice guide
EXPRESSCLUSTER X 5.3 best practice guide (released April 8, 2025)

## Best Practice Checklists
The EXPRESSCLUSTER X 5.3 best practice guide has been converted into a checklist version. There is one checklist for Windows and one checklist for Linux.

>> Note: The official EXPRESSCLUSTER documentation website contains the complete manuals.

# BestPractice
The documentation provided in this repository describes recommended parameters for a disaster recovery (DR) configuration. Two guides are included:
    
[EXPRESSCLUSTER X 4.1 best practice guide](DRBestPractice_X41.md) for Windows and Linux    
[EXPRESSCLUSTER X 5.3 (or later) best practice guide](DRBestPractice_X53.md) for Windows and Linux (released April 8, 2025)    

## Best Practice Checklists
The EXPRESSCLUSTER X 5.3 best practice guide has been converted into checklist formatted versions. There is one checklist for [Windows](DR-Best-Practices-Checklist-for-Windows.docx) and a separate checklist for [Linux](DR-Best-Practices-Checklist%20for%20Linux.docx).

>Note: The official EXPRESSCLUSTER documentation website contains the [complete manuals](https://www.nec.com/en/global/prod/expresscluster/en/doc/manual.html).
